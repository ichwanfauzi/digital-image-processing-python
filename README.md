# 🖼️ Digital Image Processing with Python & OpenCV

> Kumpulan implementasi algoritma dasar pemrosesan citra digital menggunakan Python untuk manipulasi, pemfilteran, dan perbaikan kualitas gambar.

---

## 📌 Cakupan Algoritma & Fitur

- 🔍 **Pengolahan Warna & Grayscale:** Konversi ruang warna (RGB, Gray, HSV) dan manipulasi kontras.
- 📐 **Operasi Morfologi & Thresholding:** Binarisasi citra, erosi, dilasi, *opening*, dan *closing*.
- ✂️ **Canny Edge Detection:** Deteksi tepi citra dengan teknik gradien dan analisis kontur.
- 📊 **Histogram Equalization:** Perbaikan pencahayaan dan perataan histogram citra.

---

## 🛠️ Tech Stack

- **Python 3.x**
- **Libraries:** OpenCV (`opencv-python`), NumPy, Matplotlib

---
